# 单词闪卡设计

状态：第一版已实现
最后更新：2026-09-07

## 定位

“单词闪卡”属于等待学习的第三种模式，面向几十秒到几分钟的空档。它不采用自动滚动制造“看过很多”的错觉，而使用：

> 先看英文主动回想 → 显示释义 → 自评“忘了 / 模糊 / 记住了” → 安排下次复习。

忘记的词除进入次日复习外，还会在当前轮次间隔三个词再次出现。每日进度以 20 个为轻量目标，不强制凑数。

## 已实现

- “等待学习”中的独立“单词闪卡”页面；
- 先隐藏释义，翻面后显示词义、例句和拓展；
- 三档复习调度和今日学习统计；
- 忘词当前轮次重现；
- 顺序/随机、上一个、收藏和系统 TTS 朗读；
- 导入 UTF-8 TXT 词库；
- 猫猫随词条和最近记忆状态变化。

## 复用来源

猫猫 PNG 与三套内置词库来自用户自己的项目 [`123awsd/win-floating-vocab`](https://github.com/123awsd/win-floating-vocab)。用户于 2026-09-07 明确确认这是其自有项目并允许提取复用。

本项目没有复制原应用窗口代码，而是针对 Control Tower 的 PyQt 架构重新实现页面和复习逻辑，避免同时维护两套悬浮窗运行时。内置内容包括：

- `文献术语精选_280.txt`；
- `雅思词汇真经_扩展.txt`；
- `高考3500词汇表.txt`；
- `assets/vocab-cats/` 下 32 张 PNG。

乱序词库不重复保存，随机模式在运行时完成。

## 数据边界

- 内置词库：`learning/vocabulary/`，进入 Git；
- 用户词库：`data/vocabularies/`，不进入 Git；
- 学习状态：`data/vocabulary_progress.json`，不进入 Git；
- 单词状态最多保存 20000 条；
- 用户词库只从本机读取，不发送给 DeepSeek 或其他外部服务。

当前复习间隔：

- 忘了：次日复习，并在当前轮次短间隔重现；
- 模糊：基础间隔 2 天，之后约按旧间隔的 1.5 倍增长；
- 记住了：基础间隔 3 天，之后随记忆容易度增长。

## 可继续改进
