# 长期决定记录模板

当出现需要跨对话、跨月份保留的重要决定时，把它加入对应专题文档；没有合适专题时，可以复制下面的模板创建新文档，并从 `PROJECT_MEMORY.md` 建立链接。

```text
# 功能或决定名称

状态：计划 / 已实现 / 已废弃
决定日期：YYYY-MM-DD
最后复核：YYYY-MM-DD

## 用户痛点

为什么需要这个功能或决定。

## 最终决定

已经确认、未来实现时需要保留的行为。

## 选择理由

为什么这样做；放弃了哪些方案及原因。

## 数据与隐私

保存什么、保存在哪里、是否上传、如何清理。

## 交互与边界情况

正常流程、空状态、失败状态和不应该发生的行为。

## 当前实现

状态、涉及文件、验证方式。

## 后续事项

已确认但还没有实现的部分。
```

不要记录密钥、密码、Cookie、Token、真实账号身份或不必要的个人路径。排障日志和已经失效的尝试不属于长期产品记忆，除非它们解释了一个仍然有效的架构决定。
