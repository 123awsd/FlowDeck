# 工作与灵感管理

状态：已实现
最后更新：2026-09-11

## 当前待办

“今日待办”用于表达用户此刻亲自推进的工作，而 Codex 窗口状态用于表达后台任务，两者不混为一谈。

- 可以同时激活多条未完成待办，用于表达并行推进的工作；
- 所有激活项自动排在列表最上方，以浅蓝底色、细强调线和“正在做”标记突出；
- 每一项可以独立“开始”或“暂停”，不会改变其他激活项；
- 完成激活项时自动取消激活；
- 待办只分“今日”和“稍后”；稍后是长期收纳箱，不强制用户按周维护；
- 只对今日事项排序，通过卡片右侧手柄直接拖到目标位置；正在做的事项统一置顶；
- 每项可选截止日期；到期或逾期的“稍后”事项自动进入今日，但不自动激活；
- 完成后保留创建时间、完成时间、项目、截止日期和激活次数，在“完成记录”中按月份、日期两级折叠回顾；
- 点击删除会直接从本地 JSON 删除，不进入完成记录或回收站；
- 已创建待办可以修改内容、收纳位置、截止日期和绑定项目；
- 老版待办自动兼容为“今日”，不丢失原有内容和完成历史；
- 本地待办最多保留 20,000 条，优先保留未完成事项和最近的完成记录。

数据继续保存在本机 `data/daily_todos.json`，不进入 Git。

## 项目灵感

项目灵感用于保存“与某个项目有关、但现在来不及实现”的想法，避免把它们混入今日执行清单。

- 每个自动发现的 VS Code 项目卡片都有“记灵感 / 灵感 N”入口；
- 项目卡片显示最近一条未处理灵感的简短预览；
- 弹窗中可以新增、编辑、标记已处理和删除；
- 灵感按项目路径隔离，本地保存到 `data/project_ideas.json`；
- 未处理内容优先显示，最近更新的内容排在前面；
- 全局最多保留 1000 条，优先保留未处理和最近更新的记录，防止文件无限增长。

项目路径与灵感正文不会发送给 DeepSeek 或其他外部服务。
