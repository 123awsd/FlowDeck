# 工作与灵感管理

状态：已实现
最后更新：2026-09-07

## 当前待办

“今日待办”用于表达用户此刻亲自推进的工作，而 Codex 窗口状态用于表达后台任务，两者不混为一谈。

- 任意时刻最多激活一条未完成待办；
- 激活项自动排在列表最上方，以紫色边框和“正在做”标记突出；
- 激活另一项会自动取消上一项，点击“暂停”可暂时清空当前焦点；
- 完成激活项时自动取消激活；
- 已创建待办可以修改内容、优先级和绑定项目；
- 老版本待办没有 `active` 字段时按未激活兼容，不需要迁移。

数据继续保存在本机 `data/daily_todos.json`，不进入 Git。

## 项目灵感

项目灵感用于保存“与某个项目有关、但现在来不及实现”的想法，避免把它们混入今日执行清单。

- 每个自动发现的 VS Code 项目卡片都有“记灵感 / 灵感 N”入口；
- 项目卡片显示最近一条未处理灵感的简短预览；
- 弹窗中可以新增、编辑、标记已处理和删除；
- 灵感按项目路径隔离，本地保存到 `data/project_ideas.json`；
- 未处理内容优先显示，最近更新的内容排在前面；
- 全局最多保留 1000 条，优先保留未处理和最近更新的记录，防止文件无限增长。

项目路径与灵感正文不会发送给 DeepSeek 或其他外部服务。
