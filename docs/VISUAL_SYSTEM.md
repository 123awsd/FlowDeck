# 视觉系统：轻卡通工作台

最后更新：2026-09-08

## 状态

已实现第二版，覆盖应用外壳、悬浮球、顶部导航、四个主页面、网络/对话/灵感/编辑弹窗和公共控件。功能、信息结构与本地数据逻辑保持不变。

## 设计目标

- 气质是“可靠工具 + 可爱陪伴”，不是幼儿化游戏界面。
- 用暖白表面、低饱和粉彩和细描边降低长时间置顶时的视觉压力。
- 卡通元素只出现在品牌、空状态和轻提示中，不挤占任务、Token、额度与系统指标。
- 不依赖重阴影、大面积渐变或高频动画，避免常驻运行带来额外性能负担。
- 简体中文优先，紧凑布局下仍需保证按钮文字和边框完整。

## 页面色彩

| 页面 | 主色 | 浅背景 | 用途 |
| --- | --- | --- | --- |
| 任务监控 | 粉蓝 | `#f4f9ff` | 项目、状态、Token |
| 今日待办 | 杏黄 | `#fff9ee` | 计划、优先级、进行中 |
| 等待学习 | 淡紫 | `#f8f5ff` | 前沿、课程、单词 |
| 系统监控 | 薄荷 | `#f2faf6` | 资源、磁盘、网络 |

通用表面使用奶油白 `#fffefa` / `#fffdf9`，正文使用蓝灰而非纯黑。高饱和红色只保留给真正需要处理的完成提醒或错误。

## 组件约束

- 应用外框使用 14px 视觉圆角；内容卡片使用约 12px；小按钮约 9px。
- 页面背景负责分区，卡片保持暖白；层级主要依靠 1px 细描边和留白。
- 顶部四个导航项分别继承页面色，非激活项保持暖白，不能全部回退成通用靛紫色。
- 主操作可以使用页面主色，次操作使用浅色底与深色文字。
- 状态不能只依赖颜色表达，必须同时保留文字、符号或数值。
- 长节点名、项目名和路径不得挤掉按钮；必要时省略展示并通过 Tooltip 提供完整内容。

## 卡通素材

- `assets/mascots/control-cat.png` 是控制台值班猫猫，使用透明背景，只用于标题、空状态或低干扰提示。
- `assets/icons/` 保存任务、待办、学习和系统监控的统一圆润线性 SVG 图标，避免依赖容易出现方框乱码的 Emoji。
- 素材由内置图像生成工具生成，提示词要求低饱和蓝/薄荷/奶油色、无文字、无水印、透明背景。
- 单词页继续使用用户自有 `assets/vocab-cats/`，不混入新的运行时或远程依赖。

## 下一步

- 公共 Token 与控件样式集中在 `src/codex_control_tower/theme.py`；后续新增页面必须复用该主题层，不单独创造一套高饱和主题。
- 只有在真实使用反馈表明信息层级仍不清楚时，再调整间距与字号；不为了“更卡通”增加无意义装饰。
