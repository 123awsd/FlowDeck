# 背词词库

这里保存随项目版本管理的内置词库。当前三套词库和猫猫素材来自用户自己的项目 [`123awsd/win-floating-vocab`](https://github.com/123awsd/win-floating-vocab)，经用户在 2026-09-07 明确授权复用。

不保存乱序副本，随机顺序由程序运行时完成。用户从界面导入的私人词库保存在 `data/vocabularies/`，不会进入 Git。

支持格式：

```text
word<TAB>meaning
word<TAB>pos<TAB>meaning<TAB>example<TAB>extra<TAB>category
word|pos|meaning|example|extra
```
